Set up a session

  1. Choose a whole-number tempo from 30 to 240 BPM using the slider, number field, or one-BPM minus/plus buttons. After typing, leave the field to apply the value.
  2. Turn your device volume down before pressing Start, then raise it to a comfortable level. The dot flashes with each click.
  3. Change the tempo while playing if needed. Stop keeps your tempo; Reset stops playback and returns to 120 BPM.

Example: build a four-beat phrase

Set 60 BPM: there is one second between beats. Count “1, 2, 3, 4” with four clicks and play one note per click. Repeat the phrase four times without rushing, then try 64 BPM. If the phrase becomes uneven, return to 60 and repeat.

For eighth-note practice, keep the same tempo and count “1 and 2 and 3 and 4 and,” placing each “and” between clicks. The tool does not generate these subdivisions or accent the first beat; you supply the count.

If the click is missing or uneven

Check device volume, the selected audio output, and whether the browser tab is muted. Press Stop and then Start to retry audio after interacting with the page. A browser with Web Audio support is required.

Keep this tab visible and the device awake. Background tabs, screen locking, and heavy browser workloads can disrupt timing; wireless audio can add delay. This is a practice reference, not a recording clock or a precision timing measurement.

What is saved?

The tempo and playing state live only in this open page. Reloading starts a fresh session at 120 BPM. There is no practice history, recording, microphone access, or audio export.

Clicks are generated in your browser, not downloaded as sound files. Fonts and icons load from external providers; see the site privacy information for the distinction between local tool use and website requests.
