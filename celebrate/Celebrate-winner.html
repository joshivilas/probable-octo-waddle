🏆 Declare Winners

    Choose Celebration Style:

    Turn a finished result into a celebration

    This page presents names you have already chosen. It does not draw a random winner, rank entries, or verify a competition result. Add names only when you are ready to announce them.

    Build and check a link

    1. Enter one name and press Add Winner or Enter. Repeat for each person. Names appear in the order added; duplicates are not removed automatically.
    2. Check spelling and order before continuing. There is no remove or edit control for added names. If you make a mistake, reload the page and rebuild the list.
    3. Choose a style and press Generate Celebration Link. Paste the link into a new tab and inspect it before sharing. This does not send a message to anyone.

    Example: announce a team challenge

    Add “Alex,” then “Sam.” Choose Winners Display for a page that shows both names immediately with confetti. Choose Retro Thank You for a pixel-style thank-you, or Elegant Thank You for the alternative animated design. On those two thank-you pages, recipients press the start/celebrate button to reveal names and trigger sound and confetti.

    Open your chosen result, confirm both names, and only then paste the complete link into your team chat. All three styles use the same ordered list; changing the style is not a new selection of winners.

    Current limits and troubleshooting

    The current link encoder supports Latin-1 characters, not all writing systems. Emoji and many non-Latin names prevent link generation. If an acceptable Latin-letter spelling is not available, use a different way to make the announcement rather than changing someone's name without agreement.

    Clipboard access works best on HTTPS with copying allowed in your browser. If copying fails, use the full link in the confirmation dialog when one appears, or retry in a browser that allows clipboard access. Verify the pasted result instead of relying on the “copied” message alone.

    A blank list or “Invalid data” message on the result can mean the link was cut off or altered. Copy it again with everything after # intact. Long lists produce long links, so check that your messaging service preserves the entire address. For silent thank-you pages, check tab/device volume and press the celebration button.

    Names, links, and your session

    Your working list is held in this page's memory and is cleared on reload. Generated links contain the names encoded in the URL fragment after #. Encoding is not encryption: anyone with the full link can read or change the list. There is no password, expiry, or revoke control.

    The fragment is not sent as part of the normal page request to the host, but the full link can remain in browser history, the clipboard, and shared messages. Use display names suitable for your audience and avoid confidential information. Previously shared links continue to contain their original names even after you reload this generator.
