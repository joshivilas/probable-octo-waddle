    How to create and share a winner announcement

    Turn a finished result into a celebration

    This page presents names you have already chosen. It does not draw a random winner, rank entries, or verify a competition result. Add names only when you are ready to announce them.

    Build and check a link

    1. Enter one name and press Add or Enter. Repeat for each person. Names appear in the order added; duplicates are not removed automatically.
    2. Check spelling and order. Use a name's Remove button to take it off the list; add a corrected name again if needed.
    3. Choose a style and press Create celebration link. The generated link stays visible, and the tool attempts to copy it. Open the celebration to inspect it before sharing. This does not send a message to anyone.

    Example: announce a team challenge

    Add Alex, then Sam. Choose Winners Display to show both names immediately with confetti. Choose Retro Thank You for a pixel-style thank-you, or Elegant Thank You for the alternative animated design. On those two thank-you pages, recipients press the start/celebrate button to reveal names and trigger sound and confetti.

    Turn off Play sound on reveal before starting a thank-you page for a silent celebration. Confetti finishes after five seconds and sound stops after seven seconds. Use Stop effects to end them sooner, or celebrate again to replay. Reduced-motion preferences disable confetti; the names remain readable.

    All three styles use the same ordered list; changing the style is not a new selection of winners. Editing the list or changing the style clears the generated link here so you can create an updated one.

    Copying and troubleshooting

    Clipboard access works best on HTTPS with copying allowed in your browser. If copying is unavailable or denied, the link is selected so you can copy it manually. Names in different writing systems and emoji are preserved in the generated link.

    A missing- or invalid-link message on the result can mean the link was cut off or altered. Copy it again with everything after # intact. Long lists produce long links, so check that your messaging service preserves the entire address. For silent thank-you pages, enable Play sound on reveal, check tab/device volume and audio permissions, and press the celebration button.

    Names, links, and your session

    Your working list is held in this page's memory and is cleared on reload. Generated links contain the names encoded in the URL fragment after #. Encoding is not encryption: anyone with the full link can read or change the list. There is no password, expiry, or revoke control.

    The fragment is not sent as part of the normal page request to the host, but the full link can remain in browser history, the clipboard, and shared messages. Previously shared links continue to contain their original names after you change the list or reload. Use display names suitable for your audience and avoid confidential information.
